## 1) Apply this bundle (namespace + routing)

    helm install secrets oci://ghcr.io/Franck-Sorel/home-cloud-secrets \
      --set domain=mycloud.com

or locally: `just apply secrets domain=mycloud.com`

## 2) Install Vault (upstream hashicorp chart)

    helm repo add hashicorp https://helm.releases.hashicorp.com
    # dev (single-node, unsealed out of the box) — recommend for a homelab:
    helm install vault hashicorp/vault \
      --namespace secrets --create-namespace \
      --set server.dev.enabled=true
    # HA (requires unseal/init, better for learning):
    #   helm install vault hashicorp/vault --namespace secrets \
    #     --set server.ha.enabled=true --set server.ha.raft.enabled=true

## 3) Dynamic database credentials (the true AWS-Secrets-Manager win)

Vault can mint short-lived Postgres (or MinIO) credentials:

1. Enable the DB secrets engine: `vault secrets enable database`
2. Configure a `db` connection and a role `mynotes-db` for your Postgres
3. The `mynotes` workshop app (examples/) reads username/password from Vault
   instead of storing a static DB password.

Verify: `kubectl exec -n secrets vault-0 -- vault status`
